This review covers the explicitly exported boot reconstruction sources, not the
complete Omarchy desktop, runtime filesystem, toolchain images or built boot image.

license has been assigned. Local file location does not establish original authorship.

against that allowlist before export. Coverage is not clearance.

  GPL-2.0 text retained. Kernel patches include upstream context; their local
  changes are not automatically relicensed by this review.
- Galaxy S9+ port: same lock pins SheroAbi's port. Root LICENSE, THIRD-PARTY and
  uniLoader LICENSE are retained separately. The port identifies uniLoader's

- dtbtool-exynos: the retained complete source notice credits The Linux Foundation,
  2012–2016, and contains three redistribution conditions and its disclaimer.
  The pinned pmaports APKBUILD declares MIT. These are conflicting observations,
  not interchangeable grants. Do not substitute the package label for the source
  notice. All ten imported patches retain Henrik Grimler's author, date and commit
  headers. Patch licensing still needs resolution before publication.

  preserve the actual notice rather than normalizing it away.
- BusyBox: retain the package copyright file and exact source/configuration/build
  references. The matching executable and package rebuild does not itself establish
  distribution compliance. Binary packages are absent from this preview.

## Specific unresolved evidence

The two UFS calibration files lack SPDX headers in the pinned port. Its THIRD-PARTY
file attributes them to Samsung's vendor kernel and declares GPL-2.0; this is an
upstream license assertion. Both files now exactly match the pinned vendor archive;
see VENDOR-ATTRIBUTION.md. This verifies bytes, not a new license grant. The DRM
Kconfig likewise lacks a detected SPDX header. Absence of a tag alone does not mean
absence of a license.

The port identifies its boot logo as generated by `scripts/build/make_logo.py` and
labels it GPL-2.0. The logo is not included in this source preview; reconstruction
fetches it from the pinned port. Its generation and any artwork/font inputs still
need review before distributing built images.

The saved flattened vendor DTS excerpt has no leading notice. The excerpt and its notice record have now been removed from the export.
Its hash/structural measurements remain as metadata. Resolve source ancestry before
redistributing the full DTS. Do not silently infer a per-file license
from the vendor tree's root COPYING.

Locally maintained scripts, build recipes, configurations and documentation remain
NOASSERTION. The bounded per-file content review is complete in PER-FILE-REVIEW.md; D still
needs to confirm the proposed scope and choose terms for original integration. Imported code retains its own notices.
Firmware and stock archives remain excluded; paths and hashes referring to them
are metadata, not permission to redistribute the payloads.
